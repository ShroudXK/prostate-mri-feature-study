# Data access

The original patient-derived CSV files and the private pathology linkage table are excluded from version control. Obtain access from the data owner and place the source CSV files in the repository root using the documented directory layout. Store the linkage table under `data/private/`.

The public project contains no real pathology labels. `lesion_linkage_template.csv` provides column names only; it is **not** a dataset. Do not upload patient-derived files or local `outputs/` without checking sharing permission and disclosure risk.
